# NotAnnaKav 1.1.0

NotAnnaKav 1.1.0 adds a Windows Network Monitor alongside the existing local SHA-256 file scanner.

## New: Network Monitor

- Open **Network Monitor** from the sidebar to inspect TCP IPv4/IPv6 connections and listening ports on this device.
- View process names, owning PIDs, local and remote endpoints, TCP states, and accessible executable paths.
- Distinguish localhost, all-interface, and specific-interface listener bindings.
- Filter by process, PID, address, port, state, or executable path; select connections or listeners and browse 50 entries per page.
- Refresh automatically about two seconds after each response, pause/resume polling, or refresh manually.
- Select **Scan executable** to inspect a connection owner's file using the currently selected signature database. Finish or stop any existing inspection first.

The monitor reads native Windows TCP tables and does not require a packet capture driver. Process paths may be unavailable for system, protected, or exited processes. Processes and files can change after a snapshot is taken. A listening binding does not establish reachability through a firewall or router.

## Existing capabilities

File/folder selection and drag-and-drop, an embedded starter signature database, custom database selection, live scan progress, Stop with partial results, detailed findings, local scan history, and complete JSON exports remain available. History from v1.0.0 uses the same application data location and report format.

## Downloads and installation

- **Windows x64 installer:** `NotAnnaKav_1.1.0_x64-setup.exe`.
- **Windows x64 portable:** extract `NotAnnaKav_1.1.0_windows_x64_portable.zip` and run `notannakav-desktop.exe`.
- **Checksums:** compare downloaded files against `SHA256SUMS.txt`.

Close an older running copy before installing the update. Microsoft WebView2 is required; the installer can download it if needed. The portable ZIP includes the MIT license and these release notes. Binaries are unsigned. Linux and macOS binaries are not included; Network Monitor is currently Windows-only.

## Scope and limitations

Network Monitor provides snapshots, so short-lived connections between polls may be missed. It does not capture packet contents, track bandwidth, inspect UDP, retain network history, block connections, or classify network activity as malware.

File detection remains exact SHA-256 matching against supplied signatures. The included records are a small legacy starter database, not an automatically updated threat feed. No match does not establish that a file is safe. There is no fuzzy hashing, YARA integration, archive extraction, real-time protection, or quarantine.

## Validation

Passed 7 Rust tests and 13 UI logic tests. Native Windows coverage opens a local TCP listener and connection, verifies PID ownership and the executable path, and confirms localhost binding. UI logic tests cover sidebar navigation, filtering, executable scan selection, non-overlapping requests, Pause/Resume, manual refresh, stale responses, and refresh failure handling. UI tests use a simulated Tauri bridge. Existing scanner, history, cancellation, batching, pagination, and export tests also pass.
