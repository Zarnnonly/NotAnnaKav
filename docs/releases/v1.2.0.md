# NotAnnaKav 1.2.0

Adds two Linux variants based on the original AnnaKav C SHA-256 compression code:

- Pure C CLI: build with `make`, scan with `./build/annakav-cli TARGET DATABASE_DIRECTORY`.
- Tauri desktop: Linux links the original C compression function through FFI;
  the existing interface provides progress, cancellation, history and JSON export.

Both adapters supply corrected SHA-256 padding at empty-file and block boundaries.
The CLI accepts legacy little-endian binary and hexadecimal signature records,
skips symlinks, reports matches without changing files, and supports Ctrl+C.
Windows retains its Rust hashing backend and Windows-only Network Monitor.

Linux CI builds and tests the CLI separately, and builds DEB/AppImage desktop
packages. Artifacts are available only after successful workflow completion;
Linux execution could not be verified locally because WSL could not start.
See [Linux instructions](../LINUX.md) for dependencies, commands and limitations.
