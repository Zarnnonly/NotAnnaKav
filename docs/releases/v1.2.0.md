# NotAnnaKav 1.2.0

Adds two Linux variants based on the original AnnaKav C SHA-256 compression code:

- Pure C CLI: build with `make`, scan with `./build/annakav-cli TARGET DATABASE_DIRECTORY`.
- Tauri desktop: Linux links the original C compression function through FFI;
  the existing interface provides progress, cancellation, history and JSON export.

Both adapters supply corrected SHA-256 padding at empty-file and block boundaries.
The CLI accepts legacy little-endian binary and hexadecimal signature records,
skips symlinks, reports matches without changing files, and supports Ctrl+C.
Windows retains its Rust hashing backend and Windows-only Network Monitor.

Linux CI builds and tests the CLI separately, and builds DEB/AppImage desktop
packages. Artifacts are available only after successful workflow completion;
Linux execution could not be verified locally because WSL could not start.
See [Linux instructions](../LINUX.md) for dependencies, commands and limitations.

## Downloads and installation

- **Windows x64 installer:** `NotAnnaKav_1.2.0_x64-setup.exe`.
- **Windows x64 portable:** extract `NotAnnaKav_1.2.0_windows_x64_portable.zip` and run `notannakav-desktop.exe`.
- **Linux pure C source:** `NotAnnaKav_1.2.0_linux_pure_c_source.zip`; extract, run `make`, then `./build/annakav-cli TARGET ./db`.
- **Linux Tauri source:** `NotAnnaKav_1.2.0_linux_tauri_source.zip`; follow `docs/LINUX.md` to build locally.
- **Checksums:** `SHA256SUMS.txt` covers all four packages.

Close an older running copy before updating. Windows requires Microsoft WebView2;
its installer can download it if needed. Windows binaries are unsigned. The
portable package includes the MIT license and release notes.

**Linux packages in this release are source archives, not prebuilt executables.**
GitHub Actions could not start either Linux job because the account is locked due
to a billing issue. No Linux tests ran in CI and no DEB/AppImage or CLI binary was
produced. Local WSL was also unavailable. Once Linux CI can run, its results must
be checked before publishing Linux binaries.

## Validation and limitations

Windows: 7 Rust backend tests and 13 UI logic tests passed. Linux SHA-256 boundary
and CLI integration tests are included but have not run in this environment.
Detection is exact SHA-256 matching against supplied signatures. The bundled
legacy database is not an automatically updated threat feed; no match does not
establish safety. No quarantine, real-time protection or archive extraction.
