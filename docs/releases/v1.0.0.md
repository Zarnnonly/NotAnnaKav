# NotAnnaKav 1.0.0

The first major desktop release of NotAnnaKav: local, on-demand SHA-256 signature inspection with a Tauri interface.

## Features

- Scan a single file or recursively inspect a folder, with native selection and drag-and-drop.
- Use the embedded starter signature database automatically, or select a custom database in Advanced settings.
- Watch live progress and stop an inspection while retaining clearly marked partial results.
- Inspect matching paths, sizes, SHA-256 digests, signature records, and database sources.
- Save scan history locally, reopen the latest 100 reports, and export complete reports as JSON.
- Navigate findings in pages of 50, with details created when expanded.

## Performance

- Binary SHA-256 lookup and one file-size query per opened file.
- Finding delivery in batches of up to 128 records.
- Cached history summaries with automatic indexing of existing reports.
- Buffered report serialization and background history refresh.

## Downloads

Windows x64: download the `-setup.exe` installer or extract the portable ZIP and run `notannakav-desktop.exe`. Microsoft WebView2 is required; the installer can download it if needed. The portable ZIP includes the MIT license and this release note. SHA-256 checksums are provided in `SHA256SUMS.txt`.

The Windows binaries are unsigned. Linux and macOS binaries are not included in this release.

## Scope and limitations

Detection uses exact SHA-256 matching. The embedded records are a small legacy starter database, not a maintained threat intelligence feed. A lack of matches does not establish that a file is safe. There is no real-time protection, fuzzy hashing, archive extraction, automatic signature updating, or quarantine.

Scan history persists locally and may contain sensitive filesystem paths. Stopped inspections cannot resume. The original C implementation remains available separately; the desktop application uses its Rust scanner.

## Validation

The release passed 6 Rust tests and 10 UI logic tests. These cover signature compatibility, single-file and folder scans, cooperative cancellation, indexed history recovery, finding batching, pagination, JSON export, and scan controls during slow history refresh. UI logic tests use a simulated Tauri bridge.
